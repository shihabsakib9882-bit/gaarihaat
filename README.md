# GaariHaat

Inspected car marketplace demo for Dhaka: every car has its own inspection report, and 5% holds it, refundable for 7 days.

Live: https://shihabsakib9882-bit.github.io/gaarihaat/

Design (Figma) and build (HTML, CSS, vanilla JS, GSAP) by Shihab. Cars, prices and bookings are samples; no real payment is taken. Photo credits: credits.html.
